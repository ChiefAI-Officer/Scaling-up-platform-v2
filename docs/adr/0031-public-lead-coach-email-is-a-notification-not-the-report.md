# Public lead coach email is a notification, not the report

Once a Public lead's frozen Results report is durably available through the authenticated Report access gate, the Referring coach receives a concise notification containing the Public taker's name, email, assessment, and a View report link—not the full inline report previously chosen by Spec 16. The Public taker still receives their own report, while the Scaling Up team retains exactly one concise central summary for every public completion, attributed or not; neither coach nor team notification contains the full report. This reduces assessment-data exposure in mailboxes and limits the harm of the irreducible duplicate risk in at-least-once SMTP delivery.
