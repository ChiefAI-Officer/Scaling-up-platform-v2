3 · How we know every answer lands in the right place

The risk in this kind of import is subtle: an old answer silently mapped to the wrong question corrupts a company's history without any error. So rather than eyeball it, I took each assessment on Esperto myself with a deliberately patterned set of answers, exported it, and checked that every single field came back exactly where the mapping predicts.

Rockefeller — a self-checking answer pattern

Each of the 40 sliders was set to a designed value (section + row, cycling 0–3). The export came back matching the pattern on all 40, and re-scoring reproduced Esperto's own totals exactly:

5 · Safety & what's left

Reversible in one move. The feature sits behind a switch — turning it off instantly hides it again, with Scaling Up Full import untouched. A bad import can be quarantined by a single tested command.

Ships empty, by design. No historical data is imported until a coach chooses to bring a company's rounds over — consistent with how everything in this module treats real data honestly.
